# Калькулятор арифметических выражений

**Техническое задание:**  
Приложение должно считывать с клавиатуры арифметическое выражение, содержащее числа, операции `+`, `-`, `*`, `/` и скобки `(`, `)`. Выражение может быть записано с пробелами или без них. Необходимо корректно учесть приоритеты операций и вложенные скобки, и вывести результат вычисления.

**Требования:**
1. Консольное приложение.
2. Полностью готовый к сборке и запуску код без лишних, невыполненных или пустых файлов.
3. Проект соответствует техническому заданию.
4. Реализация в процедурно-функциональном стиле (без использования классов).
5. Многофайловая структура (программа разделена на несколько `.cpp` и `.h` файлов).
6. Удобство использования: программа должна запрашивать ввод выражения и выводить результат.
7. Детальные комментарии: все переменные, функции, управляющие конструкции и сложные выражения должны быть прокомментированы.
8. Файл истории в Git (не отражён здесь), а также корректно заполненный `README.md`.
